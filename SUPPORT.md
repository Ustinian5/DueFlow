# Support

DueFlow is an open-source local-first desktop project. Support is community-oriented and best effort unless a separate paid support agreement exists. See [PRIVACY.md](PRIVACY.md) before sharing logs, diagnostics or screenshots.

## Bug Reports

Open a bug report with the issue template when DueFlow behaves incorrectly.

Include:

- operating system and version;
- Python, Node.js and Rust versions when relevant;
- whether the issue affects the Python API, desktop shell, pet overlay, exports, backup/restore or release tooling;
- exact reproduction steps;
- expected and actual behavior;
- relevant logs with private content removed.

Before filing, run the smallest relevant verification command if possible:

```bash
python -m pytest
```

For desktop issues:

```bash
cd desktop
npm run test:runtime
npm run test:smoke
```

## Feature Requests

Open a feature request with:

- the workflow you are trying to improve;
- why current behavior is insufficient;
- expected user-facing behavior;
- any privacy, offline or accessibility constraints.

DueFlow prioritizes local-first DDL management, confirmation-first extraction, transparent desktop pet interactions and open-source maintainability.

## Security Issues

Do not open public issues for vulnerabilities or private-data exposure. Follow [SECURITY.md](SECURITY.md).

## Private Data

Do not include API keys, `.env` files, raw databases, raw Inbox files, private screenshots, calendar exports with sensitive names, or diagnostics that contain secrets. Diagnostics generated by DueFlow are designed to omit raw Inbox text, task titles and source quotes, but review them before sharing.

## Unsupported Requests

The project does not provide guaranteed support for:

- modified builds that bypass release checks;
- third-party pet assets without clear usage rights;
- OpenPets runtime integration or Electron migration;
- cloud deployment as the primary product mode;
- unreleased operating system betas.
